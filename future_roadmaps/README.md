# Future Roadmaps

Draft ideas, cool features, and growth experiments for openBatarangs.

These are **working drafts** — not commitments. Each document describes a vision,
why it could attract users, and a rough phased plan.

## Index

| Draft | Focus |
|---|---|
| [01 - Remote IDE and GPU Cloud](01_remote_ide_and_gpu_cloud.md) | Let people use the device from anywhere: tunnels, web IDE, shared GPU/CUDA workloads |
| [02 - Agent Ecosystem and Plugins](02_agent_ecosystem_and_plugins.md) | Make the agent extensible: MCP, plugins, tool marketplace, multi-agent teams |
| [03 - Fine-tuning and Datasets](03_fine_tuning_and_datasets.md) | Turn the project into a local-AI training playground with curated datasets |
| [04 - Security and Sandboxing](04_security_and_sandboxing.md) | Safe multi-user access, resource limits, and trustworthy agent actions |
| [05 - Community and Growth](05_community_and_growth.md) | Leaderboards, model packs, templates, and social proof |
| [06 - Model Packs for Support and Creativity](06_model_packs_for_support_and_creativity.md) | Therapy/emotional-support models, SVG generation, ASCII art |

## How to use this directory

- Each draft is standalone and can be picked up independently.
- Status labels: `idea`, `draft`, `planned`, `in progress`.
- If a draft gets implemented, move it out of this directory or mark it `shipped`.
